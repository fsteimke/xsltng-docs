35.2. Sharing a scanner over the network

SUSE Linux Enterprise Server allows the sharing of a scanner over the network. To do so, configure your scanner as follows:

  1. Configure the scanner as described in Chapter 35, Setting up a scanner.

  2. Choose OtherScanning via Network.

  3. Enter the host names of the clients (separated by a comma) that should be allowed to use the scanner under Server SettingsPermitted Clients for saned and leave the configuration dialog with OK.
