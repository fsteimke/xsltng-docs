2.5. Managing Internet connections

To surf the Web or send and receive e-mail messages, you must have configured an Internet connection. If you have installed SUSE Linux Enterprise Server on a laptop or a mobile device, NetworkManager is enabled by default. On the GNOME desktop, you can then establish Internet connections with NetworkManager as described in the section called “Configuring network connections”.

Depending on your environment, you can choose in YaST which basic service to use for setting up network connections (either NetworkManager or wicked). For details, see the section called “Configuring global networking options”.
