2.13. Obtaining software updates

When you connect to the Internet, the updater applet automatically checks whether software updates for your system are available. When important updates are available, you receive a notification on your desktop.

For detailed information on how to install software updates with the updater applet and how to configure it, refer to the chapter about installing and removing software in the section called “The GNOME package updater”.
