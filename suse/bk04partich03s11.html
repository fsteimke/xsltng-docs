3.11. Setting default applications

  1. To change the default application for common tasks such as browsing the Internet, sending e-mails or playing multimedia files, right-click the desktop and select Settings. Now choose Default Apps.

    Figure 3.6. Default Apps

  2. You can choose an application to handle Web, mail, calendar, music, videos or photographs. Select one of the available applications from the drop-down boxes for the task of your choice.
