4.20. Authentication client

The configuration file must be in the JSON format. Verify that both autoyast2 and autoyast2-installation are installed. Use the Autoinstallation Configuration module in YaST to generate a valid JSON configuration file. Launch YaST and switch to the MiscellaneousAutoinstallation Configuration. Choose Network ServicesUser Logon Management, click Edit, and configure the available settings. Click OK when done. To save the generated configuration file, use FileSave.
