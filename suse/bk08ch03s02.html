3.2. Exporting SMT data

Procedure 3.1. Export SMT data

  1. Update your SMT server installation by running zypper up.

  2. To export your SSL certificates along with the rest of the data, run smt-data-export. Remember to keep your certificates in a safe place.

    If you do not want to export the SSL certificates from SMT, run smt-data-export --no-ssl-export.

  3. The exported configuration is now saved to smt-data-export.TIMESTAMP.tar.gz. Copy the file to a location that the new RMT server can access.
